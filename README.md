# Personal Portfolio

Welcome to my personal portfolio repository! This project is a modern, responsive, and interactive portfolio website designed to showcase my skills, projects, and professional background.

## 🚀 Tech Stack

This project is built using modern web development tools:
- **React 19** - For building the user interface.
- **Vite** - For blazing-fast build tooling and a smooth development experience.
- **Tailwind CSS v4** - For utility-first and highly customizable styling.
- **TypeScript** - For adding static type definitions to improve code quality.
- **Framer Motion** - For smooth, cinematic animations and micro-interactions.
- **Lucide React** - For sharp and consistent iconography.

## 🛠️ Installation & Setup

To get this project up and running locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone <your-repository-url>
   cd personalPortfolio
   ```

2. **Install dependencies:**
   Make sure you have [Node.js](https://nodejs.org/) installed, then run:
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   This will start the app locally (typically at `http://localhost:3000`).

## 📦 Building for Production

To create an optimized production build:

```bash
npm run build
```
This generates a `dist` folder containing all the static files you need to deploy your site.

## 🚢 Deployment

You can deploy the built application to any static hosting provider like:
- Vercel
- Netlify
- GitHub Pages

Simply upload the `dist` directory or connect your repository to your chosen platform and point the build command to `npm run build` and output directory to `dist`.
